# Install the App

There are native apps for both phones, and the site installs as a Progressive Web App anywhere else.

Installed, it runs full-screen without browser chrome, starts from cached assets, and can send you [push notifications](../account/notifications.md) — order fills, price targets, chat mentions, prediction results. The browser tab can't do the last one.

## iPhone

Download it from the **[App Store](https://apps.apple.com/app/id6762343829)**.

The listing isn't in every storefront. Where it's missing, the site offers a **TestFlight** link instead — Apple's beta channel. Install TestFlight, join through the link, and you get the same app.

To install the PWA from Safari instead: **Share** → **Add to Home Screen** → **Add**.

## Android

Download it from **[Google Play](https://play.google.com/store/apps/details?id=com.crotrade.app)**.

For the PWA: open cro.trade in Chrome, then the three-dot menu → **Add to Home Screen**.

## Desktop

Open cro.trade in Chrome or Edge and click the install icon in the address bar, or find **Install** in the browser menu.

## Afterwards

Open **Settings → Notifications**, turn push on, and grant the permission when the system asks. Nothing arrives until you do.
